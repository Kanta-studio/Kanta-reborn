PERSONAL TESTING · UNSIGNED IPA
How installation works
1
Download the iPhone/iPad file
Download the original unsigned file above and check the SHA-256 text file. The file is hosted on KANTA's own GitHub repository.
2
Use AltStore Classic
Set up the official AltStore Classic and AltServer workflow on your own compatible computer and iPhone/iPad. Sign the IPA using your own Apple account through that local tool. KANTA never requests your Apple ID or password.
3
Install and renew
Install the signed app on your own device. Free personal provisioning normally needs re-signing within seven days; some Apple capabilities, such as iCloud entitlements, may not be available in this build.
Do not open the unsigned IPA expecting iOS to install it directly. Only use your own trusted signing setup. This preview has not passed hardware audio, AirPlay/HDMI, live mic, camera, or public distribution acceptance.
WHAT THIS DOWNLOAD IS NOT
Unsigned developer preview.
No signing certificate, personal Apple credentials, Apple account token, TestFlight invite, or App Store approval is included. The IPA may be used for personal testing only. BYOL media and private Songbooks are not included in the download.
