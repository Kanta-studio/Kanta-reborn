KANTA HELP CENTER

Sing with your own library.

KANTA lets you sing with music you add yourself on iPhone, iPad and Android. Its latest code has passed automated tests and simulator builds, but the testing downloads are available; some functions still need tests on real devices.

Try three original songs offline

On a fresh installation, open My Set / Song Library to find Morning Light, Sing Together and Starlight Echo. These are short original KANTA KAR demos with timed lyrics and a bundled original instrument tone—no separate SF2 is needed for these samples.

Tap Play or Queue. You can Remove a sample and use Restore or Restore All Missing Songs to return it offline. This only affects app-managed demo copies; your imported music and SoundFonts remain untouched. Full-length commercial songs are not supplied. Real iPhone/iPad audio acceptance and signing are still pending.

1. Add your library

Open Song Library → Add Karaoke Folder and select a user-owned folder in Files or iCloud Drive. Use MIDI/KAR with a valid SF2 SoundFont, or MP3/WAV without a SoundFont. Select a whole folder and let KANTA scan it; it does not redistribute source media.

If you have an indexed title file without a compatible media container, KANTA can still index recognized titles for search. Entries appear as Catalog only and Reserve/Play stay unavailable until matching media can be validated. This is not a bypass for protected or unsupported payloads.

2. Songbook, codes and artists

Choose Home → KANTA Songbook or the Songbook button inside Host CONTROL. Search by title, artist or code. Five-digit codes on imported indexes (for example 00001) are KANTA-generated row references, not guaranteed original provider numbers; codes may change if an index is reordered.

Artist names appear when supplied by your library. Where the source lacks artist metadata, KANTA shows “Artist not provided”; you can edit and save artist names locally. Choose Prepare complete songbook CSV then Share / Save songbook to export a metadata-only list. Your recordings/audio are not included.

Private website Songbook: how to unlock

On your iPhone/iPad open KANTA Songbook and choose Create private website copy. Share the encrypted .kanta-book to the browser device and note the 32-character code displayed on your phone. Visit Private Songbook, choose the file, then enter the matching code. Both are required. Search your songs, flip pages, download a CSV or choose Print/Save as PDF. No files or search metadata are sent to KANTA servers. The code is not an expiring OTP or LAN Remote PIN. Printed or downloaded songbooks are not encrypted.

3. Save a karaoke session to Favorites

After you actually play songs, tap End Session in Host. KANTA asks whether to save those played songs as a named collection; queued-but-never-started songs are not included. From Home → Saved Favorites, rename, delete or Load to Up Next. The current queue stays intact. Songs that are missing from your authorized library or are catalog-only are skipped rather than forced to play.

4. Live Soundcard / Vocal FX

In Host → Soundcard · Vocal FX, choose Dry, Room, Studio, Hall, Cathedral, Plate or Echo, and adjust Reverb, Echo, Bass, Treble and Mic Level. Scoring reads the dry mic input. Live monitoring requires microphone permission and a supported wired-headphone, USB audio or line-out route; it is off on startup. Built-in speaker, Bluetooth and AirPlay live-monitor paths are disabled to reduce feedback and delay.

External amplifier note: If your microphone is plugged straight into an amplifier instead of into an audio interface recognized by iOS as an input, KANTA cannot apply vocal FX to it. A real iPhone/iPad with compatible hardware is required to verify routing, latency and feedback behavior.

5. Party SFX Pad, owner samples and voice polish

From Host, open Party SFX Pad and tap Applause, Cheering, Drum Roll, Air Horn, Laughter, Ta-Da, Ding or Sad Trombone. Use Stop SFX to mute one-shots and the dedicated SFX volume slider to adjust their level. Long-press a sound button to import your own 12-second / 12-MB maximum audio clip from Files; the clip is stored locally, and Restore original reverts to KANTA's original procedural sound.

On a PIN-paired Remote, Party SFX Pad triggers the Host's sounds; no personal clips are transferred to the Remote. Within Soundcard, Vocal style provides OPM Ballad, Pop Star, Rock Concert, Duet, Studio Clean and Party Karaoke presets, plus compression, noise gate, de-esser, doubler and delay-time adjustments. The output peak limiter remains active.

Coming later: Full vocal harmonies remain future placeholders. Experimental monophonic pitch correction exists in the app source but starts off and has not been validated for real-device audio latency or quality. Remember that monitoring your actual voice requires its audio to enter the iPhone/iPad via a compatible wired/USB input.

6. Pair a companion Remote

On Android: Open Control on the phone playing your music and tap Use this phone as Host. Keep both Android phones on the same trusted Wi-Fi, and share the private pairing code with the second phone. On that phone, open Control, paste the code and tap Connect. You can then search songs, reserve, pause, play, skip and remove queued requests. Tap Stop Host to revoke access. The pairing code is private: do not post it publicly. This feature has passed an automated emulator check but still needs testing on two separate phones. It does not work between Android and iPhone yet.

On iPhone/iPad: Keep both Apple devices on the same trusted Wi-Fi or wired LAN. Start KANTA Host and check its six-digit Pairing PIN. Open Remote on the second device, discover/select the Host and enter the PIN. The Remote can search Host library metadata, reserve songs and control the queue/transport.

The current PIN-authorized LAN connection is not encrypted. Do not use it on public or untrusted networks.

7. Troubleshooting

  • Offline use: download source files in Files before going offline.
  • Library access: if your folder moved or access expired, reselect it from Song Library.
  • No MIDI sound: choose a valid user-owned SF2 and try a smaller fallback bank if memory is limited.
  • Unknown code or artist: confirm the printed Songbook belongs to the same imported index order; add missing artist metadata in Songbook.
  • Song in Favorites will not play: verify the source folder is still accessible and the selected song is playable, not catalog-only.
  • Mic FX silent: check microphone permission, explicit monitor toggle and compatible wired/USB routing. Never turn on speakers at high gain near an active microphone.
  • Scoring unavailable: scoring is opt-in and needs a usable microphone and a validated melody target; not every file supports it.
  • Stage performance: low-end devices may reduce visual complexity; media is not silently compressed.
  • iCloud Save: uploading prepared files depends on Apple's iCloud availability. Deleting KANTA backups does not delete original user folders.

Export a private KANTA bug report

To help diagnose Soundcard, microphone or app-launch problems, open KANTA → Settings → Support & Diagnostic Reports. Turn on Keep local diagnostic events before reproducing the problem. Try the same steps again, then choose Prepare support report, followed by Review / Share report. Select the destination yourself; KANTA never uploads it automatically.

The JSON report contains time-stamped technical event codes, app/build/OS information, rough device category, safe microphone/output state and DSP engine choice. It contains no singing recordings, song/library contents or PINs. Events are capped at 200 and seven days. Use Erase local diagnostic history, or switch recording off, to remove it from your device.

For real iOS crash stacks, Apple TestFlight feedback or a separate user-selected .ips report from iPhone/iPad Settings → Privacy & Security → Analytics & Improvements → Analytics Data may be needed. Review system reports carefully: they can contain details beyond the app's redacted JSON. A previous-session interruption marker does not prove a crash.

Private testing installation: BetaDrop can distribute a signed IPA via Safari, but cannot sign KANTA. Your device must be covered by an Apple developer Ad Hoc/development profile. KANTA never asks testers to upload signing certificates; TestFlight is also an option.

7. Beta support and privacy

If you have an actual internal TestFlight invitation, use TestFlight → KANTA → Send Beta Feedback. Include app version, device/OS, audio route and reproducible steps, but not private songs, SoundFonts, credentials or full library files. A public support contact is still required before external release; the private GitHub repository is not a support portal.

Stage Display & Audio Setup

Connect a supported external screen over HDMI/USB-C, or an AirPlay destination supporting independent iOS external scenes. Open Karaoke Host; KANTA sends the stage (lyrics/backgrounds) to the extended display and keeps controls on the main device. On an AirPlay mirroring-only route, the system mirrors the entire phone instead. Confirm the Host's External Stage status before a party.

Use Host → Audio Inputs & Diagnostics to inspect input and output, choose a preferred available mic, verify its dry level when scoring/monitoring is active and adjust scoring offset. Hardware I/O buffer time is not measured end-to-end latency; mic monitoring still requires safe wired/USB output.

Singers, playlists & music between songs

Enter a singer in Host or the paired Remote before selecting Reserve. Use the queue arrows to change order while preserving the singer name. Open Home → Saved Favorites → New Playlist, search your song library, choose a playable first song and add/remove/reorder more titles. The saved playlist does not include audio copies.

Use Host → Between-Song Music to import your own MP3/WAV/M4A/CAF/AIFF audio (up to 150 MB) with no compression. Turn on Auto-play between songs. Music loops only while the karaoke transport is stopped and fades out on playback; leaving Host disables it. KANTA does not provide licensed songs or stream intermission tracks.

Private Songbook on Android

In My Set, choose the option to save a private Songbook file. Save the separate 32-character code that KANTA shows you: you will need it to open the file later. You can also choose a private Songbook file from your device and enter its code to import its song list. Only titles and other song details are exchanged, never recordings. Android-to-iPhone file exchange still needs testing on real devices.

Prefer a simple list? Use Export CSV, but remember that CSV files are not password-protected.
