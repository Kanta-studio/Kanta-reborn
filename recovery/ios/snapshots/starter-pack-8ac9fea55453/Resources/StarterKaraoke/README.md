# KANTA original starter resources

Three original lyric-bearing KAR demos and a procedural triangle-wave SF2.
Generated deterministically by `Tools/generate-starter-kar.py`; SHA-256 hashes
are in `manifest.json`. No third-party music, recordings or instrument samples.
These are project-generated assets, not an assertion of CC0 or legal clearance.
See `Docs/STARTER_KARAOKE_PACK.md` for provenance, storage, playback and release gates.

The app bundles this directory read-only. Only private managed KAR copies can be
removed; restoration uses these originals offline. Never add user media here.
